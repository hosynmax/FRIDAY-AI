# نقشه محصول FRIDAY AI

## تعریف
FRIDAY AI یا «فرایدی» یک دستیار شخصی هوشمند Android، فارسی‌محور، متصل به سرور اینترنتی و دارای موتور اجرای فرمان کنترل‌شده است. مدل زبانی درخواست را می‌فهمد و برای آن برنامه‌ریزی می‌کند؛ ابزارهای مجاز Android عملیات واقعی را انجام می‌دهند.

اصل محصول: «می‌فهمد، برنامه‌ریزی می‌کند و با اجازه کاربر اقدام می‌کند.»

## گروه‌های قابلیت
### گفت‌وگو
- چت چندمرحله‌ای فارسی و انگلیسی
- پاسخ جریانی، توقف، تلاش مجدد، کپی، جست‌وجوی تاریخچه
- مدیریت چند مکالمه و حذف مکالمه
- پاسخ با زمینه مرتبط و خلاصه‌سازی تاریخچه بلند

### صوت
- Push-to-talk در نسخه اول
- تبدیل گفتار به متن با انتخاب زبان
- پاسخ با Text-to-Speech، تنظیم سرعت و صدای قابل انتخاب
- مکالمه صوتی تمام‌صفحه با حلقه موج انتزاعی
- Wake word فقط opt-in و با foreground notification آشکار در نسخه بعدی؛ ضبط مخفی ممنوع

### فرمان و کنترل
- تشخیص intent و استخراج پارامتر از زبان طبیعی
- ساخت ActionPlan ساختاریافته
- بررسی امکان اجرا، permission، پیش‌شرط و ریسک
- نمایش کارت preview و تأیید
- اجرای action از API رسمی Android
- گزارش نتیجه واقعی، خطا یا محدودیت

### ابزارهای دستگاه
- بازکردن برنامه‌ها و صفحه‌های مجاز تنظیمات
- ساعت، تاریخ، محاسبه و تایمر
- چراغ‌قوه با API رسمی و در صورت پشتیبانی سخت‌افزار
- یادداشت، وظیفه و یادآور
- افزودن event تقویم از مسیر رسمی و با تأیید
- بازکردن لینک و مسیر در برنامه مناسب
- انتخاب عکس/فایل از Picker سیستم
- تماس، پیامک و ایمیل فقط به‌صورت پیش‌نویس یا handoff؛ کاربر ارسال نهایی را تأیید کند
- مکان، مخاطب و فایل فقط با درخواست روشن و permission جداگانه

### جست‌وجو و تحقیق
- وب‌گردی از Provider سمت سرور
- عنوان، دامنه، تاریخ، snippet و لینک منبع
- خلاصه چندمنبعی با تفکیک واقعیت از تفسیر
- اعلام نبود دسترسی وب در صورت قطع اینترنت یا نبود ابزار
- محتوای وب داده غیرقابل اعتماد است و نباید دستور مدل را تغییر دهد

### فایل و دانش
- انتخاب فایل با Storage Access Framework
- نسخه اول: PDF متنی و فایل‌های متنی مجاز
- خلاصه‌سازی، پرسش و پاسخ، استخراج نکات و تبدیل به پیش‌نویس task/note
- اطلاع‌رسانی واضح پیش از upload
- محدودیت حجم، رمزگذاری و OCR در صورت نیاز باید مشخص باشد؛ فایل اسکن‌شده یا رمزدار ممکن است پشتیبانی نشود
- فایل موقت پس از پردازش بی‌دلیل نگهداری نشود

### بهره‌وری
- یادداشت با عنوان، متن، برچسب و جست‌وجو
- وظیفه با اولویت، مهلت و وضعیت
- یادآور و اعلان محلی
- تقویم روز/هفته و ساخت پیش‌نویس event
- routineهای ساده، شفاف و قابل توقف

### حافظه شخصی
- حافظه مکالمه جاری
- حافظه بلندمدت اختیاری و opt-in
- مشاهده، اصلاح، export و حذف هر مورد حافظه
- قابلیت خاموش‌کردن حافظه
- اطلاعات ذخیره‌شده حقیقت قطعی تلقی نشود؛ در صورت عدم اطمینان سؤال پرسیده شود

### هوش مصنوعی و سرور
- Cloud mode برای مدل آنلاین
- Self-hosted mode برای Ollama روی سرور مالک
- Offline tools برای ابزارهای محلی
- Provider Adapter برای تعویض مدل بدون انتشار APK
- نمایش مدل، اتصال، latency و سهمیه
- کلیدهای مدل فقط در Secret Manager سرور

## نقشه صفحات
1. Onboarding: زبان، معرفی حریم خصوصی و توضیح مجوزها
2. Home: هسته صوتی، وضعیت سرور، فرمان سریع و ابزارهای محبوب
3. Chat: پیام‌ها، پاسخ stream، source، action card، ورودی و پیوست
4. Voice: حلقه موج، متن زنده، کنترل شنیدن و صحبت
5. Action Preview: عملیات، مقصد، پارامتر، ریسک، مجوز، تأیید/لغو
6. Tools: یادداشت، task، timer، چراغ‌قوه، جست‌وجو و ابزارها
7. Tasks: امروز، آینده، تکمیل‌شده و فیلتر
8. Notes: جست‌وجو، برچسب، ویرایش و حذف
9. Calendar: روز/هفته و eventها
10. Web Research: جست‌وجو، منبع، تاریخ و خلاصه
11. Files: انتخاب، وضعیت پردازش و خروجی تحلیل
12. Memory: موارد ذخیره‌شده و کنترل هر مورد
13. History: جست‌وجو، دسته‌بندی و حذف مکالمات
14. Service Status: health check، provider، latency، quota و خطا
15. Settings: زبان، صدا، مدل، ظاهر، privacy، permission و درباره
16. Admin Panel: پنل مجزای مالک سرور، نه بخشی از اپ کاربر

## ناوبری
ناوبری موبایل: خانه، گفت‌وگو، ابزارها، فعالیت‌ها و تنظیمات. صفحات تخصصی از ابزارها یا تنظیمات باز شوند. در صفحه عریض از Navigation Rail استفاده شود.

## مسیرهای مهم
- پرسش: Home → Chat → Send → Streaming → Follow-up.
- فرمان: Voice/Text → Intent → Preview → Permission/Confirm → Native Action → Result.
- یادآور: Parse title/time → Preview → Confirm → Schedule → Notification.
- تحقیق: Query → Search → Validate sources → Cited summary → Open source.
- فایل: Select → Explain upload → Parse → Summarize → Optional save with confirmation.

## وعده‌های صادقانه
FRIDAY AI سیستم‌عامل جایگزین یا برنامه دارای root نیست. نمی‌تواند هر برنامه یا تنظیم گوشی را بدون محدودیت کنترل کند. کیفیت پاسخ به مدل، سرور، اتصال و سهمیه بستگی دارد. رایگان بودن مدل به معنی رایگان و نامحدود بودن میزبانی یا پردازش نیست.

## معیار موفقیت
- ورود سریع به چت یا فرمان صوتی
- وضعیت Listening/Thinking/Executing/Offline کاملاً روشن
- هیچ اقدام حساس بدون preview و تأیید انجام نشود
- نتیجه فقط پس از گزارش واقعی ابزار موفق اعلام شود
- داده شخصی قابل مشاهده، export و حذف باشد
- در نبود اینترنت، ابزارهای محلی همچنان کار کنند
